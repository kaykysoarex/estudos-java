# Fundamentos de Java

Biblioteca pessoal para os estudos práticos de Java; começa na linguagem e não inclui fluxogramas ou pseudocódigo.

## Ordem de estudo

1. Fundamentos Java · 2. Condicionais · 3. Repetitivas · 4. Modularização · 5. Strings · 6. Arrays · 7. Matrizes · 8. Coleções · 9. Problemas · 10. Revisão.

| Conceito | Pergunta mental |
|---|---|
| variável | Onde guardo um valor? |
| if | Preciso executar isso? |
| while | Até quando repetir? |
| for | Quantas vezes repetir? |
| método | Posso separar essa tarefa? |
| array | Preciso guardar vários valores do mesmo tipo? |
| matriz | Preciso de linhas e colunas? |
| ArrayList | Preciso de uma lista que mude de tamanho? |
